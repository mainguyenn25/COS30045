# Power Appliances Website

## Overview

Power Appliances is a three-page educational website about household 
appliance energy consumption in the Australian market.

The website was developed using:

- HTML5
- CSS3
- JavaScript

No external JavaScript libraries or frameworks are used.

## Pages

The website contains three HTML pages:

1. Home
2. Televisions
3. About Us

## Features

### Navigation

All pages contain a consistent navigation menu.

The navigation includes:

- Power Appliances logo
- Home link
- Televisions link
- About Us link
- Hover effects
- Active page indicator


### FAQ Accordion

The Home page contains a FAQ section.

FAQ answers are hidden by default.

JavaScript is used to:

- Reveal answers when a question is clicked
- Hide answers when clicked again
- Change the + icon to a − icon

### Energy Calculator

The Home page contains an interactive Appliance Energy Calculator.

Users can enter:

- Appliance power in watts
- Average hours of use per day
- Electricity price in cents per kWh

The calculator uses JavaScript to calculate:

- Daily energy consumption
- Monthly energy consumption
- Yearly energy consumption
- Estimated monthly electricity cost
- Estimated yearly electricity cost

The calculator also validates user input and displays error messages 
when invalid values are entered.

### Footer

All pages contain a footer with:

- Current year
- Student name
